1. ระบบโปรไฟล์

Profile System

จัดการข้อมูลส่วนบุคคลอย่างครบถ้วน พร้อมการตรวจสอบความถูกต้องและความปลอดภัย:

  • เปลี่ยนชื่อ - นามสกุล และคำแนะนำตัว (Bio)
  • อัปโหลดรูปประจำตัว (Avatar) พร้อมพรีวิวสด & เช็คขนาดไฟล์ (≤ 5MB)
  • จัดการอีเมล พร้อมระบบตรวจสอบความซ้ำซ้อน
  • จัดการเบอร์โทรศัพท์ด้วย Regex Validation
  • ระบบเปลี่ยนรหัสผ่านที่ปลอดภัย

2. Login & Session Timeout

Session Control

ระบบจัดการการเข้าสู่ระบบและควบคุมเวลาการใช้งานอัตโนมัติ:

  • เข้าสู่ระบบและออกจากระบบด้วย POST CSRF Guard
  • เซสชันหมดอายุอัตโนมัติเมื่อไม่ใช้งาน {{ session_timeout_minutes|default:60 }} นาที
  • แสดงเวลานับถอยหลังแบบเรียลไทม์บนแถบ Navbar
  • สามารถตั้งเวลาได้ในหลังบ้าน (Django Admin)
  • บันทึกเหตุการณ์ Timeout เข้าสู่วงรอบความปลอดภัย
ตั้งเวลาเซสชันในหลังบ้าน

3. ป้องกัน Cyber Security

Security Hardened

การปกป้องเว็บแอปพลิเคชันตามมาตรฐานความปลอดภัยระดับสูง:

  • ป้องกันการโจมตีแบบ Brute-force ด้วย django-axes
  • ระบบ Audit Log บันทึก IP, User-Agent, และเวลาทุกกิจกรรม
  • การป้องกัน XSS, Clickjacking (DENY), MIME-Sniffing
  • คุกกี้ปลอดภัย HttpOnly + SameSite=Lax
  • ซ่อนรหัสผ่านใน Log ด้วย Sensitive Parameters

วิธีต่อยอดโปรเจกต์ในอนาคต:

  1. สร้างแอปพลิเคชันใหม่ด้วยคำสั่ง python manage.py startapp your_app
  2. ลงทะเบียนแอปใน config/settings.py ในส่วน INSTALLED_APPS
  3. สร้างเทมเพลตที่ขยายจาก {% extends 'base.html' %} เพื่อให้ได้ Navbar, Sidebar และความปลอดภัยโดยอัตโนมัติ
  4. เพิ่มลิงก์เมนูใน Sidebar ที่ไฟล์ templates/base.html
